# Product Motion Grammar — meaning before transitions

A pattern is a story-level explanation that Remotion, HTML seek(t) or WebGL may implement. It is **not a new rendering engine**. Use only when the transformation makes the next product state easier to understand.

| Pattern | Source state | Transform | Destination / meaning |
| --- | --- | --- | --- |
| `text-to-ui` | Short product statement | Text geometry follows/locks to a UI label | Claim becomes grounded in a real app |
| `ui-to-data` | Authentic UI panel | Camera/selection extracts one measured datum | Show the underlying mechanism |
| `path-draw` | Route, trace or flow | Stroke grows with a meaningful process variable | Explain ordered traversal / causality |
| `data-to-number` | Verified intermediate values | Compose values with traceable logic | One result, with source disclosure |
| `progress-along-path` | Current location on a path | Marker and completed segment share a progress variable | Communicate progress (not estimated accuracy) |
| `state-color-transition` | One state classification | Transition token based on state thresholds | Distinguish status change, include color-blind encoding |
| `number-to-ui` | Outcome figure | Match-cut same glyph/anchor into authentic UI | Tie explanation back to user result |
| `object-to-brand` | Persistent object | Morph into *approved* mark geometry | Resolve consistent visual idea into brand |

## Contract

For each named pattern capture: `input`, `event_trigger`, `mapped_variable`, `source_of_truth`, `geometry_anchor`, `output`, `fallback`, `claim_refs`, `read_hold`, `accessibility`. Prefer consistent direction of motion and stable glyph geometry through handoffs. If no truthful value exists, use a clearly labelled non-numeric concept or remove the shot.

## UI fidelity

- Use supplied capture or approved reconstruction; preserve original labels, hierarchy and product/version states.
- Reconstructed UI is NOT automatically evidence of an actual shipped feature.
- For each screen-to-data transition cite the UI asset and product claim IDs. If geometry cannot match between abstract and UI states, use an editorial cut instead of deceptive continuity.
- Distinguish animation of *data relationships* from simulation of actual historic or live data. An animated map is not itself GPS evidence.

## Avoid

Unmotivated wipe/zoom, every line moving simultaneously, invisible re-mapping of color, ever-changing unit scale, falsely precise telemetry, or physically implausible movement presented as real. Complex motion without information value is a reason to simplify.

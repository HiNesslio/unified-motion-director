# Visual Direction Presets — selectable, never compulsory

Director Intelligence is independent of visual taste. Choose **one dominant** preset; secondary presets may donate a limited technique but must not create contradictory typography, movement or color policy. User art direction overrides all defaults. Do not hardcode Apple, white backgrounds or SaaS layout into `SKILL.md`.

- **minimal-editorial**: typographic hierarchy, negative space, quiet camera, precise holds. Helpful for complex messages requiring trust.
- **kinetic-product**: authentic UI, shared-element match cuts, stable screen geometry and motivated interactions.
- **data-explainer**: one consistent data-to-shape encoding, labeled scales/states, source and uncertainty disclosures.
- **cinematic-launch**: material/space/camera progression, fewer hero moments, deliberate visual resolution.

Each film `LOOK.md` should define actual project tokens (type, accent, surface, easing, camera, spacing, forbidden effects, evidence status); preset labels alone are insufficient. Mix for a reason, not to average every aesthetic reference.
